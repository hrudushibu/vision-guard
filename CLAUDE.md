## 🎯 Project Mission

You're working on **Vision Guard** — a computer-vision security framework that detects physical security events from video. Your job is to help build intelligent video monitoring that catches real threats while respecting privacy.

## 🚧 Current Status

This project is in **early development**. The computer vision pipeline, detection algorithms, and video processing approach are being designed.

## 📹 Computer Vision Principles

### 1. Real-Time First
Live monitoring requires real-time performance. Optimize detection pipelines for speed.

### 2. Privacy Matters
Video surveillance is invasive. Build privacy controls from day one—face blurring, zone masking, data retention limits.

### 3. Minimize False Positives
Balance sensitivity. Too many false alarms and operators ignore the system. Too few and real threats slip through.

### 4. Explainable Detections
When an alert fires, show exactly what triggered it. Annotate the video frame.
